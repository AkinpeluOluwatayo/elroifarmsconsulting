# El-Roi Farms Consulting — Official Website

Static, lightweight, high-performance website for **El-Roi Farms Consulting**, the agricultural consulting and farm investment advisory arm of El-Roi Farms.

## Overview
- **Brand**: El-Roi Farms Consulting
- **Focus**: Agricultural Investment Planning, Farm Business Plans, Feasibility Studies, Financial Budgets & Projections, Farm Management Advisory across South-West Nigeria (Lagos, Ogun, Oyo, Ibadan, Osun, Ondo).
- **Contact/WhatsApp**: `08104883602` (`+2348104883602`)

## Tech Stack
- HTML5 (Semantic elements, JSON-LD structured data)
- Tailwind CSS via CDN (extended palette: Deep Forest Green `#064E3B`, El-Roi Gold `#D97706`, Warm Cream `#FAFAF9`)
- Vanilla JavaScript (Zero dependencies, fast execution)
- Fully static, ready for instant hosting on Vercel, Netlify, GitHub Pages, or standard static web servers.

## Structure
```
/
├── index.html        # Complete page with hero, services, pathways, form, FAQs, etc.
├── css/
│   └── custom.css    # Custom scrollbar, focus states, glassmorphism, gold gradients
├── js/
│   └── main.js      # Mobile nav, interactive pathways, WhatsApp link generator, accordions
├── robots.txt        # Search engine instructions
└── sitemap.xml       # SEO XML Sitemap
```

## Setup & Local Preview
Simply open `index.html` in any browser, or serve using any static server:

```bash
npx serve .
# or
python3 -m http.server 8000
```
